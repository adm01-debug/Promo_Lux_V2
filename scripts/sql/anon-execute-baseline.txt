# Baseline de EXECUTE do papel 'anon' em funcoes do schema public
#
# Fonte: pg_proc + has_function_privilege('anon', oid, 'EXECUTE') no projeto
# de producao pttzwlbidamjssqiqb (medido em 2026-11-25: 64 de 207 funcoes).
#
# Por que existe: o PostgreSQL concede EXECUTE a PUBLIC em toda funcao nova, e
# 'anon' herda esse grant. Boa parte desta lista e default herdado, nao decisao:
# as edge functions da API publica chamam RPCs com a anon key
# (supabase/functions/public-api/index.ts chama verify_api_key, touch_api_key e
# check_api_key_rate_limit) e ha endpoints sem login (pesquisa por token, status).
#
# Contrato do guard scripts/check-function-grants.sh:
#   * funcao public executavel por anon FORA desta lista  -> FALHA (exposicao nova);
#   * funcao desta lista que deixou de ser executavel     -> FALHA (linha zumbi:
#     remova a linha junto com o REVOKE, para o baseline nao mentir);
#   * funcao nova que nasce executavel por anon            -> FALHA (por design).
#

# REVOKE EXECUTE + ajuste da linha aqui, com o chamador migrado antes. Nunca
